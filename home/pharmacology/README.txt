# The Pharma Insight V1 Website

Open `index.html` in a browser to preview the website.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design
- `script.js` — mobile navigation, active navbar, buttons, contact-form demo
- `assets/logo.png` — your uploaded logo

## Important
The mock-test buttons, premium test button, YouTube link and contact form are currently front-end demo connections.
Replace them with your real quiz URLs, payment/test-series URLs, YouTube channel URL and form/backend endpoint when ready.
